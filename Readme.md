# 🌸 Nolana Floral Studio

## Project Overview

Nolana Floral Studio is a web application developed as a group project for the Web Application Development course at Centennial College.

The application aims to provide an online platform where customers can explore flowers and related floral products. It will include functionalities for managing flower products and user accounts.

The project is being developed in multiple phases, beginning with backend development, database integration, and API testing.

## Project Objectives

- Develop a functional flower shop web application.
- Implement a backend using Node.js and Express.js.
- Integrate MongoDB Atlas as the database.
- Develop RESTful APIs for managing users and flower products.
- Implement Create, Read, Update, and Delete (CRUD) operations.
- Implement user authentication and authorization.
- Test API endpoints using Postman.
- Develop a frontend and integrate it with the backend in a later phase.

## Project Development Phases

### Part 1 – Backend Development and API Testing

- Initial project setup.
- MongoDB database and collection configuration.
- Backend development using Node.js and Express.js.
- RESTful API development.
- CRUD operations for users and flower products.
- Authentication and authorization.
- API testing using Postman.

### Part 2 – Frontend Development

- Develop the user interface using React.
- Implement frontend functionality.
- Integrate the frontend with backend APIs.
- Test the complete application.
